AnimeDialog 1.1.4 使用说明

AnimeDialog 在本机把动漫或电视剧视频整理成按人物分类的台词本。可以对照视频修改原文、中文、时间和人物，再导出 Word、HTML、TXT 或 SRT。首次取得模型后可离线处理；也可自行配置大模型 API 翻译原文。

第一次启动

  1. 运行 Windows 安装包。安装在当前用户目录，不需要预先安装 Python。
  2. 打开“模型与工具”。已有模型可以直接“导入”；没有模型时点击“下载 / 续传”。可调整模型存放文件夹。状态悬停能查看下载来源与 SHA256，“校验”能检查完整性。
  3. 常规识别需要 large-v3-turbo；声音分类需要声音切分与特征模型；中文翻译与语义姓名候选需要 Qwen3 8B。精细重识别另外使用 large-v3。模型合计约 7 GB，项目缓存和预览需要额外空间。
  4. 软件已包含 FFmpeg、Whisper.cpp 和 llama.cpp。通常无需修改程序路径。若使用自己的引擎，可在“模型与工具”指定对应 EXE。

导入与处理视频

  1. 点击“新建作品”，填写名称并选择保存位置。一个作品可以有多集，人物资料在全部剧集中共享。Windows 11 x64 为当前交付平台。
  2. 点击“添加视频”一次选择多部视频。左侧剧集的“设置”菜单中选择“上移剧集 / 下移剧集”调整顺序。
  3. 选择一集，在剧集“设置”菜单中打开“语言、音轨与字幕”。选择原声语言和音轨，也可使用内嵌字幕或附加 SRT、ASS。外挂字幕可指定为原声字幕或中文对照；自动判断不确定时请手动指定。
  4. 视频有烧录字幕时勾选画面字幕提取。输入字幕区域比例并“查看字幕区域”，调整到覆盖文字。区域格式为左、上、宽、高，每项为 0～1，可分多行设置多个区域。按视频中的实际位置调整，OCR 结果仍需听校。
  5. “开始处理”处理当前选中的一集；选择“全部剧集”后则依次处理全部集。队列显示阶段、进度与失败原因。选中任务可暂停、继续、取消或重试。关闭软件时会请求暂停；已经完成的片段保存在检查点中。

默认优先尝试显卡运行，原生推理引擎报错后改用 CPU。重型模型顺序使用，翻译阶段开始前释放声音模型。模型缺失时，任务给出具体缺失名称，可补齐后重试。中文原声保留一份原文，不重复生成相同的中文译文。

无字幕时翻译原文

  1. 先完成语音识别。未安装 Qwen3 而希望手动或通过 API 翻译时，在“语言、音轨与字幕”取消“本地生成中文翻译和人物姓名候选”。
  2. 手动翻译：选中台词，点击“手动翻译”或按 Ctrl+3，在中文对照框填写译文。修改会自动保存，来源标记为“人工翻译”；改动文字后需重新校对。
  3. 大模型翻译：点击工具栏“翻译原文”或按 Ctrl+T。可翻译选中台词，或只补充当前集、整个作品的空白译文。中文原声不重复翻译。
  4. 选择本地 Qwen3 可离线翻译。选择“大模型 API”时，填写兼容 Chat Completions 的 API 地址、模型 ID 和 API Key。地址可填写 Base URL（如 https://你的服务/v1）或完整 /chat/completions 地址；远程服务使用 HTTPS，本机服务允许 HTTP。免认证本机服务的密钥可留空。更换地址后需重新填写密钥。
  5. API 模式只将原文及上下文发送到指定服务，不上传视频或音频。密钥由当前 Windows 账号加密保存在应用设置中，不写入作品或导出文件。清空密钥并开始翻译会移除该地址已保存的密钥。
  6. 空白译文自动填写，仍需文字校对；已有译文或处理期间修改过的台词保留原结果，新译文进入“识别、翻译与回导建议”，可用 Ctrl / Shift 多选后接受或忽略。人物审核独立保存。任务可暂停、继续和重试，已完成批次保留。

对照视频审核

左侧选择剧集或人物，右侧搜索或按类型、审核状态筛选。点击台词会定位并播放对应视频；播放器下方的“倍速”可选 0.5×、0.75×、1×、1.25×、1.5×、2×、3×、5×；可以循环本句、前后句跳转。“画幅”可选原始比例、16:9、4:3、1:1、21:9、铺满。原始比例保留视频宽高比；固定比例将画面调整到所选比例并居中，窗口或播放区域调整后自动适应；铺满填满播放区域。拖动三个区域的分隔条可以调整宽度，也可分别调整剧集/人物、视频/队列、台词列表/编辑区的高度。程序退出时记住布局、播放速度、画幅和音量。菜单“视图”或 Ctrl+0 恢复默认布局。“清除筛选”恢复全部剧集、人物和审核状态。无法播放的编码可生成带相同时间轴的兼容预览。

操作作用
人物已确认表示人工核对了说话人；不会同时把原文和中文标为已校对。
文字已校对表示人工核对了文字。与人物审核分别保存。
多人分句为中文分句分别选择人物。每句时间可以留空，留空表示仅用整段时间定位；需要精确边界时自行填写并回看。
批量归类按 Ctrl 或 Shift 多选台词，加入现有人物或新人物；仍保留文字校对状态。
改名与合并人物应用于作品中的全部剧集和声音样本，旧名字保留为别名。
新增 删除 拆分 合并补充漏句、移除误识别、修改句子结构。拆分位置须人工确认；合并保留原分句归属与备注；删除可以撤销。
撤销与重做菜单“编辑”，或 Ctrl+Alt+Z、Ctrl+Alt+Y。台词列表/视频获得焦点时 Ctrl+Z、Ctrl+Y 也可撤销项目操作；文字框中这两个快捷键只撤销、重做文字输入。自动保存记录修改历史。

“更多操作 → 设为人物声音样本”用于单一人物、已经人工确认且声音清晰的片段。建立样本后，“用声音样本推荐本集人物”会提出匹配建议。同一作品后续集数也会使用这些样本。声纹相似与上下文推理不能保证真实人物身份，最终仍需人工确认。

按台词裁剪视频

  1. 在“台词审核”用 Ctrl / Shift 选中一句或多句台词，点击列表下方“片段”、右键“加入片段列表”或按 Ctrl+Shift+K，进入独立“片段导出”标签页。Ctrl+1 返回选句，Ctrl+5 打开片段页；可跨集添加或重复添加同一句。
  2. 拖动片段或点击上移、下移改变导出顺序。片段列表获得焦点时，Ctrl+↑ / Ctrl+↓ 调序，Delete 移除，空格预览。
  3. 双击片段或点击预览，播放到片段结尾暂停；F6 开启循环。“调整时间”只修改当前片段边界，不改变台词原记录。列表及顺序自动保存到作品项目中。
  4. 选择最高 1080p、720p 或原分辨率。“分段导出”在指定位置创建子目录，按序编号保存 MP4；“按顺序合并导出”保存一个 MP4。使用原视频及所选音轨，正常速度输出，保持比例；合并统一首段画幅与帧率，其他片段留边适配，无声片段保留静音。边界按视频帧精度裁剪，先预览核对。
  5. 导出在播放器下方任务队列运行，支持暂停、继续和重试，重启后可以复用已完成片段。“打开导出目录”查看成果。原视频不修改，已有文件不会被覆盖；文件名冲突时请重新命名。

连续审核与快捷键

按 F1 查看完整快捷键清单。审核人物与校对文字分别保存：Ctrl+Enter 只确认当前文字并跳到下一条可见句，不会同时确认人物。F9 在当前筛选范围寻找下一待核，到末尾后从头继续；按人物/文字筛选时检查对应状态，其他范围检查两项。画面文字只检查文字，歌词也支持人物待核筛选。

升级到 1.1.4

先关闭 AnimeDialog，再运行 1.1.4 安装包安装到原目录。原有项目、模型、人物和台词编号继续使用，无需数据迁移。

重新识别与修改比较

选择一句，在“更多操作”点击“重新识别本句”，使用 large-v3 处理该片段。软件保留当前人工版本，新结果进入“识别、翻译与回导建议”，左右比较后可接受或忽略。接受机器建议后，与本次建议有关的审核状态会重新打开；声音匹配不影响文字校对，选句重识别不会清空已有中文和人物归属。回导的人工审核状态会保留。接受操作可以撤销。若原版本在建议生成后又改动，会明确提示冲突。

审核统计与机器版本

每次自动处理的原始结果单独保存在台词数据中，人工编辑不会覆盖它。“审核 → 审核统计”显示人物与文字的审核覆盖、待确认数量，以及机器结果与已人工核对版本的差异，并保存为项目文件夹中的“审核统计.json”。没有人工参考时不会显示虚假的准确度。拆分、合并及过长文字不参与原始识别差异计算；译文质量仍需单独校对。

导出与离线 HTML

  1. 在“导出台词本”选择格式、范围与排序。当前筛选结果可以按指定剧集、人物导出；Word、HTML、TXT 可以按人物分组。
  2. SRT 始终按时间排序，每集独立保存，可选原文、中文或双语，人物名也可以关闭。多人分句时间未核对时保留整段时间，不伪造逐句时间轴。
  3. HTML 可以直接用浏览器离线打开。选择本地对应视频后，点击时间回看，打开“人工审核与修改”为待复核台词选择现有人物。
  4. 完成网页修改后点击“保存 HTML 副本”。返回软件用“文件 → 导入旧台词 / HTML”导入该副本；新增记录直接添加，修改记录先进入建议窗口，比较后再合并。

旧成果与文件保存

已有 AnimeDialog 项目可通过“打开项目”选择其文件夹。旧 JSON 或 HTML 台词成果可使用“文件 → 导入旧台词 / HTML”导入；对白、歌词与画面文字按原有类型保留。自动推测不会视为人工审核完成。

项目数据存放在项目文件夹的 project.sqlite；cache 保存模型任务检查点和预览。视频保留在原位置，移动后可以重新关联。建议在软件关闭后复制整个项目文件夹备份；卸载不会删除项目或下载的模型。

处理失败时

缺少模型：安装指定模型后重试。磁盘不足：释放项目所在磁盘的空间。视频移位：重新关联视频。任务中断：打开项目后选择该任务“继续 / 重试”。显卡失败：查看队列信息，CPU 回退可能较慢。OCR 或语义判断错误：通过台词编辑和建议比较修正，所有自动台词初始都需核对。

本版暂不提取 PGS 等图片字幕轨，请使用原声识别或画面字幕 OCR。API 翻译失败时请核对服务地址、模型名称、密钥、网络和配额，再通过任务队列重试；也可切换本地模式或手动翻译。本版不执行关机操作。默认本地处理；仅在主动选择 API 翻译时发送原文和上下文。
